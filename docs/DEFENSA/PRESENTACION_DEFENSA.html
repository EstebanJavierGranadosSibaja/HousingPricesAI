Análisis crítico

Limitaciones, sesgos y ética

Dataset

Una sola ciudad (Ames) y un periodo (2006–2010): no generaliza automáticamente a otras regiones ni a hoy.

Modelo

Heterocedasticidad: subestima viviendas de lujo. Gap de sobreajuste del RF (~60%).

Sesgos

Geográfico (Neighborhood) y temporal: reflejan el mercado de ese lugar y época.

Ética: usar el vecindario de forma determinista puede reforzar desigualdades territoriales. El sistema es apoyo a la decisión, no una tasación oficial.
Conclusiones

Solución completa, reproducible y honesta

  • Ciclo completo: formulación → EDA → Pipeline → 2 modelos → CV → tuning → evaluación → app → análisis crítico
  • Modelo final: Random Forest (RMSE 27.449, R² 0.902); LR+log como alternativa más estable no operativa
  • Diferenciadores: sin data leakage, selección por validación cruzada y significancia estadística (p ≈ 0.13)
  • Mejoras futuras: más variables, permutation_importance, validar en otras regiones/periodos
